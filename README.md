# Sam's Boat Repair — private prospect preview

A custom Next.js website concept for **Sam's Boat Repair Fiberglass & Gelcoat Experts** in Bacliff, Texas.

## Creative direction

**Damage disappears. Craftsmanship doesn't.**

The site is intentionally not a generic marine-repair template. It uses a dark Gulf-water palette, sea-glass accents, coral repair markers, technical scan/radar details, animated boat/fiberglass visuals, an interactive before/after finish reveal, moving review-theme marquee, and a project-intake console.

The visual language is based on the thing customers repeatedly praise: repairs that blend back into the boat and finish work that looks factory-clean.

## Interactive features

- Animated hero boat with surface scan beam
- Floating boat / moving water / technical orbit system
- Drag-controlled BEFORE / AFTER finish reveal
- Animated review-theme marquee
- Animated repair targeting / radar section
- Animated process line
- Interactive project type + damage area selector
- Copyable project brief
- One-tap Call Sam CTA
- Fixed mobile action dock
- Reduced-motion accessibility fallback

The project intake does **not** submit or store customer data in preview mode.

## Development

```bash
npm install
npm run dev
npm run build
```

`previewMode` is enabled in `config/site.ts`, and the site metadata is configured as `noindex, nofollow` until approval.
